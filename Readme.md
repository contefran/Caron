# Caron

A wannabe tool to visualize the outcome of a simulation in real time

## Usage

At the moment it reads a file (`Simulation.npy`), so if you don't have it you need to create one.
- You can do it by running `Make_mock_sim.py`: it creates n steps of an mxm simulation (a trasforming cone moving through the background)
The visualizator has only 3 features so far: start the visualization, stop it, and adjust the number of frames per second
